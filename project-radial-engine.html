Radial Engine — Parametric CAD Design

A fully parametric radial engine model exploring multi-cylinder combustion architecture. Built in Onshape.

Onshape embed goes here — paste the iframe code from Onshape's Share/Embed dialog

The challenge

Model a working combustion engine from first principles, then extend the design into a radial, multi-cylinder configuration as an added engineering constraint.

Approach & tools

  • Built in Onshape using cylindrical constraints and revolve features
  • Extended single-cylinder logic into a radial array to model multi-cylinder timing and clearance
  • Applied system integration to keep all cylinders parametrically linked to a shared crank geometry

Outcome & what I learned

Deepened understanding of combustion engine architecture and multi-body constraint management in a fully parametric environment.
